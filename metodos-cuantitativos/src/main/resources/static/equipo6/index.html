Flujo Máximo

Calcula el flujo máximo en una red dirigida usando el algoritmo de Edmonds-Karp (BFS iterativo sobre la red residual).

Algoritmo

Edmonds-Karp aplica BFS para encontrar el camino aumentante más corto en cada iteración, garantizando complejidad O(VE²).

Nodos especiales

El nodo verde es la fuente y el rojo es el sumidero. Los demás nodos son intermedios.

Aristas saturadas

Una arista aparece en rojo cuando su flujo alcanza su capacidad máxima (cuello de botella).
