¿Por qué se transforma Min Z en Max W?
Problema original
Min Z = cTx
×(−1)
Problema auxiliar
Max W = −cTx
Al final
Resultado real
Zmin = −W*

El algoritmo Simplex está diseñado para maximizar. Multiplicar el objetivo por −1 invierte el sentido de optimización, permitiendo usar el mismo algoritmo. Al obtener W*, revertimos el signo para obtener el costo mínimo real Z.
